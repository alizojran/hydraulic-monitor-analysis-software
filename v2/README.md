# HMAS v2.0 — Vue 3 frontend

The Vite project for the Hydraulic Monitor & Analysis System dashboard.
See [the root README](../README.md) for product overview and feature list.

## Develop

```bash
npm install
npm run dev          # http://localhost:5173/
```

## Build

```bash
npm run build        # → dist/
npm run preview      # serve dist/ locally
```

## Stack

Vue 3 · TypeScript · Vite · Pinia · vue-i18n · WebGL2 · Web Worker · 自研 radix-2 FFT
